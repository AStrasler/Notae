# The Notae of Anatomy & Physiology I

Five study figures built on the form of the medieval notae from the *Ars Notoria*.

- Unit 1: the Body, Tissues, Skin
- Unit 2: Bone, Joints

`index.html` shows all five in order. The figures are drawn by `notae.js` from the data at its top, so editing a line there changes the figure. The `images` folder holds each nota as a standalone SVG for saving or printing.

Read each from the center outward, one ring at a time, then follow the red lines to the corners.
